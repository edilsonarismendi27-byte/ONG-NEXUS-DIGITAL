# ONG Nexus Digital

Projeto acadêmico fictício desenvolvido para praticar **HTML, CSS e JavaScript** durante os estudos de Engenharia de Software.

## Sobre o projeto

A ONG Nexus Digital é uma proposta de site para apresentar iniciativas de inclusão digital e educação. O repositório reúne arquivos recuperados de diferentes etapas de desenvolvimento do trabalho.

## Tecnologias

- HTML5 — estrutura das páginas
- CSS3 — estilos e apresentação visual
- JavaScript — interações e formulário demonstrativo

## Estrutura

- `index.html` — página inicial simples
- `cadastro.html` — formulário de interesse
- `objetivos.html` — página em desenvolvimento
- `eventos.html` — página em desenvolvimento
- `style.css` — estilos recuperados
- `script.js` — script recuperado

## Como visualizar

Baixe o repositório e abra `index.html` no navegador. Algumas páginas e recursos podem estar incompletos, pois os arquivos foram recuperados de versões diferentes.
