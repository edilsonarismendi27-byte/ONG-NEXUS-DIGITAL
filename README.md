## 📖 Sobre o projeto

A **ONG Nexus Digital** é uma ONG fictícia criada como tema de um trabalho acadêmico. O objetivo do site é apresentar iniciativas de inclusão digital, educação e acesso ao conhecimento.

Este repositório reúne **arquivos recuperados de diferentes etapas** do desenvolvimento, servindo como registro do meu aprendizado em desenvolvimento web.

## 🎯 Objetivos

- Praticar a estruturação de páginas com HTML
- Desenvolver estilos e layouts utilizando CSS
- Explorar interações básicas com JavaScript
- Aprender a organizar e documentar um projeto no GitHub

| `style.css` | Estilos visuais | Arquivo recuperado |
| `script.js` | Interações em JavaScript | Arquivo recuperado |

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas
- **CSS3:** cores, espaçamento e apresentação
- **JavaScript:** interações e comportamento do formulário

## ▶️ Como visualizar

1. Baixe os arquivos do repositório utilizando **Code → Download ZIP**.
2. Extraia a pasta no computador.
3. Abra `index.html` no navegador.

> **Atenção:** como os arquivos vieram de versões diferentes, algumas páginas, links ou funcionalidades podem não funcionar integralmente.
